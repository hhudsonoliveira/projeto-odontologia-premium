2. **Navegue até a pasta**

### Breakpoints

| Dispositivo | Largura | Layout |
|-------------|---------|--------|
| **Mobile** | 320px - 767px | 1 coluna, menu hamburger |
| **Tablet** | 768px - 1023px | 2 colunas, menu adaptado |
| **Desktop** | 1024px - 1439px | 3-4 colunas, menu completo |
| **Large Desktop** | 1440px+ | Layout completo, max-width 1400px |

### Mobile First

Todo o CSS foi desenvolvido com **Mobile First**, ou seja:

1. Estilos base para mobile (320px+)
2. Media queries com `min-width` para telas maiores
3. Progressive enhancement

**Exemplo:**
```css
/* Mobile (base) */
.grid {
  grid-template-columns: 1fr;
}

/* Tablet (768px+) */
@media (min-width: 768px) {
  .grid {
    grid-template-columns: repeat(2, 1fr);
  }
}

/* Desktop (1024px+) */
@media (min-width: 1024px) {
  .grid {
    grid-template-columns: repeat(3, 1fr);
  }
}
```
